# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-06-30

### Added
- 🎨 Complete portfolio website with modern UI
- 🌓 Dark mode with system preference detection
- 📱 Fully responsive design with mobile menu
- ✅ Todo application with filters and search
- ⏱️ Pomodoro timer with statistics
- 📝 Markdown editor with real-time preview
- 🎯 Project showcase with 4 featured projects
- 💾 LocalStorage persistence for all apps
- 🚀 Production-ready build configuration
- 🦊 GitLab Pages deployment support
- 🐙 GitHub Pages deployment support
- 🔍 SEO optimization with meta tags
- ⚡ Performance optimization (opt-level = "z")

### Features
- Animated hamburger menu for mobile
- Smooth transitions and animations
- Professional design system
- Reusable components (Button, Input, Card, Modal)
- Custom hooks (useTheme, useLocalStorage, useInterval)
- Clean architecture with separation of concerns

### Technical
- Rust 2024 Edition
- Dioxus 0.7 framework
- WebAssembly target
- Tailwind CSS styling
- Optimized production build (LTO, strip, etc.)
